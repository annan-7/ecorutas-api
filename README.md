# ECORUTAS API

Public, read-only FastAPI catalog of 65 nature routes in Chile. All seed fields
are stored in `src/data/routes.json`, with fixed UUIDs and timestamps. Requests
never connect to a database or write files. No authentication is required.

## Local development

Requires Python >=3.11.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
uvicorn src.main:app --reload
```

No environment file, database, migrations, or seeding step is required.

## Endpoints

- `GET /health`
- `GET /api/v1/routes` — same paginated response: `items`, `total`, `skip`, `limit`.
  Default limit is 20; use `?limit=100` to fetch all 65 routes in one request.
  Supports `skip`, `limit` (1–100), `difficulty`, and partial `location` filters.
- `GET /api/v1/routes/search?q=torres` — case-insensitive name search.
- `GET /api/v1/routes/{route_id}` — fixed UUID; unknown IDs return 404,
  malformed UUIDs return 422.

The GET paths and response fields are preserved. POST and DELETE are no longer
supported (405). IDs previously generated by SQLite are replaced by stable
catalog UUIDs; clients should fetch the catalog again to obtain these IDs.
CORS allows any origin by default, without credentials. Optionally set
`CORS_ORIGINS` to a comma-separated list to restrict browser origins.

## Vercel

Import this repository as a Python project with the repository root as the root
directory. `vercel.json` explicitly selects the native FastAPI framework.
`[tool.vercel]` in `pyproject.toml` selects `src.main:app`; Vercel routes
requests directly to this app without a catch-all rewrite. `api/index.py` is
retained only as a compatible import entry point.
`requirements.txt` installs the runtime dependencies. No database or secrets
are needed. Leave Build Command and Output Directory overrides unset, and use
the repository root as Root Directory. Remove obsolete DATABASE_URL, INITIALIZE_DATABASE, and SEED_DATABASE
settings; they are no longer used. Use `CORS_ORIGINS=*` for public browser access.

The JSON catalog is loaded relative to the Python package, independent of the
working directory. It is explicitly included in the Vercel function and Python
package. Cold starts do not rely on ASGI lifespan events or writable storage.
Edit the JSON and redeploy to update the catalog. Keep IDs stable for existing
routes. Actual production deployment requires a Vercel project and deployment.

## Quality

```bash
ruff check src tests
black --check src tests
mypy src
pytest --cov=src
```

Docker is optional: `docker compose up --build` starts the same static API.

For deployment validation, request `/health` and `/api/v1/routes?limit=100`
on the deployed domain. `/` and `/api/index` are not application endpoints;
404 responses there are expected. A successful deployment should report
`{"status":"ok"}` at `/health`. Verify the deployment uses the latest main
commit rather than redeploying an older deployment.
